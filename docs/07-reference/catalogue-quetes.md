# Catalogue des quêtes

Les sept quêtes livrées, leurs étapes, leurs objectifs et leurs récompenses.

**Statut : livré.** Trois quêtes de trame, quatre annexes. Le contenu est volontairement
court : le contenu durable de WizardMC, c'est le monde et les autres joueurs.

---

## Comment la lire

| Terme | Ce que ça veut dire |
|---|---|
| **Étape** | Les étapes s'enchaînent **dans l'ordre écrit** |
| **Objectif** | Les objectifs d'une même étape se remplissent **dans n'importe quel ordre** |
| **Maîtrise** | Un seuil, pas une monnaie : elle ouvre les quêtes suivantes |
| **Déblocage** | La **seule** source de montures du jeu |

---

## 1. La trame

Trois chapitres, tous donnés par le **Forgeron**. Un seul maillon est proposé à la fois.

### Chapitre 1 — *Le premier souffle*

> « Le Sanctuaire vous a recueilli. Il attend quelque chose en retour. »

| | |
|---|---|
| **Étapes** | Se présenter au Forgeron, puis abattre cinq gobelins |
| **Récompense** | 40 d'expérience, 5 de maîtrise, 3 lingots de fer, 8 pains |
| **Déblocage** | — |

La première étape est de **parler**, pas de combattre. À dix minutes, un joueur a besoin
de quelqu'un avant d'avoir besoin d'un adversaire.

### Chapitre 2 — *Ceux qui mènent*

> « Une bande sans chef se disperse. Trouvez celui qui la tient. »

| | |
|---|---|
| **Étapes** | Trois : abattre, ramasser, revenir parler |
| **Récompense** | 90 d'expérience, 10 de maîtrise, 1 totem de bande |
| **Déblocage** | **Le Husky** |

La leçon de la bande gobeline, appliquée : une troupe a un chef.

### Chapitre 3 — *Ce qui dort dans les fanges*

> « Quelque chose remue sous les marais. Allez voir. »

| | |
|---|---|
| **Étapes** | Trois : se rendre quelque part, abattre, ramasser |
| **Récompense** | Expérience, maîtrise, 2 diamants |
| **Déblocage** | **Le Crabe de jade** |

Le premier objectif de déplacement de la trame, et donc la première quête qui apprend à
suivre un chemin à l'écran.

## 2. Les annexes

Quatre, toutes données par le Forgeron. Elles se prennent dans n'importe quel ordre.

### *Vermine des caves*

> « Les gelées s'installent partout. Personne ne les regrette. »

| | |
|---|---|
| **Étapes** | Deux |
| **Objectif** | Abattre des gelées |
| **Récompense** | 6 boules de gelée |
| **Déblocage** | — |

### *Un lit de plumes*

> « Le Forgeron dort mal. Ce n'est pas votre problème, mais il paie. »

| | |
|---|---|
| **Étapes** | Trois |
| **Objectifs** | Ramasser, puis **remettre** au Forgeron |
| **Récompense** | 2 émeraudes |
| **Déblocage** | — |

**La seule quête qui utilise une remise.** Les objets quittent l'inventaire : il faut les
avoir sur soi au moment de parler.

### *Le belvédère*

> « On dit qu'on voit toute la vallée depuis la crête. »

| | |
|---|---|
| **Étapes** | Une |
| **Objectif** | Atteindre un point, rayon 16 blocs |
| **Récompense** | 60 d'expérience, 5 de maîtrise |
| **Déblocage** | **Le Corbeau des augures** |

La quête la plus courte du jeu, et elle donne une monture volante. C'est délibéré : une
récompense forte pour un effort d'exploration, accessible à un joueur seul.

### *Écailles et cendres*

> « Les gelées de lave laissent un noyau que les forges convoitent. »

| | |
|---|---|
| **Maîtrise minimale** | 20 |
| **Étapes** | Deux |
| **Objectif** | Réunir 4 noyaux en fusion |
| **Récompense** | 140 d'expérience, 15 de maîtrise, 1 diamant |
| **Déblocage** | **Le Drakelet d'or** |

La seule quête à exiger une maîtrise minimale. Sans elle, un nouveau joueur passerait son
temps à mourir dans les profondeurs sans comprendre pourquoi.

## 4. Les montures encore sans quête

Quatre quêtes débloquent une monture. **Six montures attendent la leur** :

| Monture | Rareté |
|---|---|
| Yak des cimes | Commune |
| Renard des braises | Rare |
| Ours brun | Rare |
| Murmure-de-givre | Épique |
| Ours des glaces | Épique |
| Griffon | Légendaire |

> Une monture déclarée sans quête **ne s'obtient pas**. Les relier est une tâche ouverte.

Sans WizardQuest, toutes les montures sont ouvertes — c'est un comportement de repli, pas
une intention.

---

## 5. Les cinq types d'objectif

| Type | Ce qu'il demande | Employé par |
|---|---|---|
| `TALK` | Parler à un personnage | La trame |
| `KILL` | Abattre | Cinq quêtes |
| `COLLECT` | Ramasser | Quatre quêtes |
| `REACH` | Se rendre quelque part — **un marqueur est exigé** | Deux quêtes |
| `DELIVER` | Remettre — **les objets quittent l'inventaire** | *Un lit de plumes* |
