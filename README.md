Cette documentation répond à quatre questions différentes, et chacune a sa porte
d'entrée. Lisez celle qui vous concerne : personne n'a besoin de tout lire.

## Comment lire cette documentation

Les conventions, les statuts de livraison, la règle de préséance entre documents
et la marche à suivre pour contribuer sont dans
**[Comment lire cette documentation](docs/00-lire-cette-doc.md)**.

Deux choses à savoir tout de suite :

- **Aucun extrait de code** dans les sections 00 à 07. Les valeurs sont données en
  tableaux, les procédures en étapes numérotées. Les spécifications de la section
  90 en contiennent, pour les développeurs.
- **Le code est la vérité.** Quand un tableau de cette documentation contredit un
  fichier de configuration livré, c'est le fichier qui a raison et le tableau qui
  est à corriger. Signalez-le plutôt que de contourner.
